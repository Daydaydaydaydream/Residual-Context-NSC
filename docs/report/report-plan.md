## 3. 每节要点

**1 引言**（2–3 段）
- 段 1：NAS 里训练每个候选太贵 → 免训练启发式 → NSC 只读架构规格。
- 段 2：加法对层序免疫 → 给具体数字（121.820169804 两行相同，参数与 MACs 也相同）。
- 表 1：三种上下文评分都能区分顺序，但方向不同（主方法偏好窄 FFN 在前，共同加权相反）。
- 段 3：研究问题（排序 / 方向 / 选择）；明确"敏感 ≠ 预测更准，负结果也是结论"。

**2 方法**
- 2.1 结构负载 `q_l = 0.5·d·f_l·s^4`、累积 `Q_l`、首层为 0；一句话说清 `s^4` 的来历。
- 2.2 权重 `w(Q;β)=1+βQ/(1+|β|Q)` 与 `S(β)`；三种 β 情形。
- 2.3 性质：`w(0)=1`、`0<w<2`、正负偏移对称；`β=0` 即加性消融；α = −β。
- 另两个对照：共同加权（joint）与指数形式（exponential），说明它们分别检验"作用对象"与"函数形式"。

**3 数据与评估**
- 200 条、100/100、Post-LN、AdaEmb、mem_len 192；宽度 {64,128,256,512}、深度 2–16。
- 指标：ρ、τ_b（全对 + 180 配对）、并列；分数 12 位有效数字后比较。
- 选择：10M/20M/30M/50M × k=1,3，遗憾值；200 次固定种子。
- 纪律：dev 选 β → 冻结 → final 跑一次。配对 180 对不独立。

**4 机制检查**
- `check_starter.py` 全绿；`verify_adapter.py` 在 200 配置上验到 `ablation == original_nsc`（最大相对差 3.1e-15）。
- 表 1 的换序例：主方法差 0.005022，共同加权方向相反（−0.070839）。
- 极限：`Q_1=0` 首层权重恒为 1；`β→0` 回基准；`β→±∞` 趋于 0 与 2。

**5 结果**
- 5.1 排序：先报基线 ρ=0.969745，再报主方法 0.972817（+0.0031）；指数形式 0.972241；共同加权 0.970153。
- 5.2 选择：表 3（待填）；基线遗憾值：10M k=1 时 1.941、50M k=3 时 0.089；随机 13.285 / 6.043。
- 5.3 强度：图 1；`β=-100` 是峰值，`-1000` 回落到 0.9716 → 说明最优值贴边。

**6 讨论与限制**
1. 提升空间小：基线已 0.9697，增量 0.003 可能落在噪声内。
2. 混杂：规模主导；AdaEmb 占 7.8%–97.9%，10M 档尤甚。
3. `Q_l` 只是结构代理（Post-LN）。
4. 单条标签、无种子方差；最终集不是独立基准。
5. **选择偏差**：β 在开发集上按 ρ 挑出，报告里的 ρ 本身带乐观偏差。

- 一句结论（成立 / 不成立 / 方向性发现）。
