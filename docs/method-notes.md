## 1. 符号速查

| 符号 | 读作 | 含义 | 本面板取值 |
|---|---|---|---|
| `d` | 隐藏宽度 | 每层向量维数，所有层相同 | 64 / 128 / 256 / 512 |
| `L` | 层数 | decoder 层数 | 2–16 |
| `H_l` | 第 l 层头数 | 注意力头个数 | 逐层给出，`d` 必须能被整除 |
| `f_l` | 第 l 层 FFN 宽度 | FFN 中间层维数 | 512–2048 |
| `s` | 初始化标准差 | 权重初始化尺度 | 固定 0.02 |
| `psi_MP(m,n,s)` | MP 容量 | 随机矩阵期望 log-det 的解析近似 | `nsc_utils` / `nsc.py` |
| `A_l` | 注意力容量 | 该层注意力投影的容量贡献 | 由 `psi_MP` 组合 |
| `F_l` | FFN 容量 | 该层两个 FFN 投影的容量贡献 | 同上 |
| `S_0` | 原始 NSC | `sum_l (A_l + F_l)`，基线 | — |
| `q_l` | 结构负载 | 该层 FFN 分支把信号放大的倍数 | §2 |
| `Q_l` | 累积负载 | 当前层**之前**各层 `q` 之和，首层为 0 | §2 |
| `beta` | 方向与强度 | 负=递减，正=递增 | 网格 `0, ±0.1, ±1, ±10, ±100, ±1000` |
| `w(Q; beta)` | 上下文权重 | 乘在 FFN 容量上的系数，取值 (0, 2) | §3 |
| `S(beta)` | 项目评分 | 加权后的总分，越大越"好" | — |

**三句话读法**

1. `q_l` =「这一层把信号放大了几倍」。两次矩阵乘法各贡献一个 `s^2`，再乘宽度 `d` 与 `f_l`，ReLU 砍掉一半。
2. `Q_l` =「走到这一层时，前面所有层累计放大了几倍」。累加，不含自己。
3. `S(beta)` =「注意力容量照常算，FFN 容量按前序上下文打折或加成，最后加起来」。

## 2. 结构负载 `q_l` 的推导

假设：权重独立服从 `N(0, s^2)`，输入各向同性且与权重独立，忽略归一化，FFN 为未归一化的双层 ReLU 分支。

设输入每维二阶矩为 `v`：

```text
第一层后：  E[z_i^2] = d · s^2 · v
ReLU 后：   二阶矩减半          （对称高斯输入下 E[ReLU(z)^2] = E[z^2] / 2）
第二层后：  E[y_i^2] = f_l · s^2 · (d s^2 v / 2) = q_l · v

q_l = 0.5 · d · f_l · s^4
```

因此 `q_l` 是**输出与输入的二阶矩比**。`s^4` 来自两次线性映射，**不是笔误**。

> 与单矩阵容量区分：单个矩阵 `psi` 的首阶展开期望是 `d·f·s^2`，只含**一个** `s^2`；
> 它衡量矩阵自身容量，`q_l` 衡量两层复合的信号增益，两者含义不同，不能互换。

## 3. 权重与两个对照

```text
w(Q; beta) = 1 + beta·Q / (1 + |beta|·Q)

S(beta) = sum_l [ A_l + w(Q_l; beta) · F_l ]
```

| 情形 | 权重 | 含义 |
|---|---|---|
| `beta < 0` | `1 / (1 + \|beta\| Q)` | 递减：前面越重，后面 FFN 权重越低 |
| `beta = 0` | `1` | 基准 = 原始 NSC = 加性消融 |
| `beta > 0` | `1 + beta Q / (1 + beta Q)` | 递增：前面越重，后面越高 |

**两个预先声明的对照**（代码里是 `NSC_SCOPE` / `NSC_FORM`）：

- **共同加权（joint）**：同一权重同时作用于 `A_l + F_l`，用来检验收益是否只来自 FFN。
- **指数形式（exponential）**：`beta<0` 用 `exp(-|beta| Q)`，`beta>0` 用反射 `2 - exp(-|beta| Q)`。
  与主形式同为零点 1、同向、同 (0,2) 范围，只是尾部更陡。

**性质**

- `w(0; beta) = 1`：首层 `Q_1 = 0`，不受影响。
- `Q >= 0` 时 `0 < w < 2`：权重恒正、有界。
- `w(Q; +|beta|) + w(Q; -|beta|) = 2`：两个方向的偏移相对基准对称。
  **但排名变化不保证对称**——只有两个架构的增量反号，它们才会交换位置。
- 极限：`beta -> -inf` 时 `w -> 0`，`beta -> +inf` 时 `w -> 2`。

## 4. 一个算得出来的例子

开发集 `config_0_j0`：`d=128`、`L=5`、`H=[2,4,4,8,8]`、`f=[1071,640,1286,800,1871]`。

| 层 | H | f | A_l | F_l | q_l | Q_l |
|---:|---:|---:|---:|---:|---:|---:|
| 1 | 2 | 1071 | 25.194 | 89.920 | 0.010967 | 0.000000 |
| 2 | 4 | 640 | 25.305 | 57.307 | 0.006554 | 0.010967 |
| 3 | 4 | 1286 | 25.305 | 104.791 | 0.013169 | 0.017521 |
| 4 | 8 | 800 | 25.361 | 69.890 | 0.008192 | 0.030689 |
| 5 | 8 | 1871 | 25.361 | 141.434 | 0.019159 | 0.038881 |

`S_0 = 589.868`（与 `check_starter.py` 的期望值一致，可作实现锚点）。

代入 `beta = ±1`：

| beta | 各层 w（1→5 层） | S(beta) | 相对 S_0 |
|---:|---|---:|---:|
| 0 | 1.000, 1.000, 1.000, 1.000, 1.000 | 589.868 | — |
| −1 | 1.000, 0.989, 0.983, 0.970, 0.963 | 580.068 | −9.800 |
| +1 | 1.000, 1.011, 1.017, 1.030, 1.037 | 599.669 | +9.800 |

`beta` 换号时每个 `w-1` 精确反号，总分增量也精确对称（`|beta|=100` 时 ±261.902）。

## 5. 受控换序例（表 1 的数据来源）

`d=128`、`H=[4,4]`、`s=0.02`，FFN 宽度 `[256,512]` 与 `[512,256]`：

| 评分 | [256, 512] | [512, 256] | 差值 |
|---|---:|---:|---:|
| 原始 NSC（beta=0） | 121.820170 | 121.820170 | 0.000000 |
| 主方法（beta=−1，FFN） | 121.697831 | 121.692809 | 0.005022 |
| 共同加权（beta=+1，joint） | 122.008670 | 122.079509 | −0.070839 |
| 指数形式（beta=−1） | 121.697671 | 121.692476 | 0.005195 |

读法：原始 NSC 两行完全相同（加法对顺序免疫）；三种上下文评分都能区分，但**方向不同**——
主方法/指数偏好 A（窄 FFN 在前），共同加权偏好 B。这说明"权重作用于谁"会改变偏好方向。

**该对架构没有训练标签**，所以它只证明"评分对层序有反应"，不能证明"预测更准"。

## 7. 假设边界（哪些话不能说）

1. **`Q_l` 不是激活方差**：面板全为 Post-LN，LayerNorm 会重新缩放激活，`q_l` 的矩推导前提（无归一化）并不成立，它只是**结构代理**。
2. **方向无机制含义**：`beta>0` 若更好，也只说明该评分方向更有预测价值，不能推出层间存在真实的"增强"。
3. **增益很小**：原始 NSC 的 ρ 已达 0.9697，主方法 0.9728，差 0.003，很可能落在选择噪声内。
4. **最优 `beta` 贴边**：主方法在 `beta=-100` 取峰值，`-1000` 回落到 0.9716，说明最优值可能只是开发集拟合。
5. **单标签**：每架构一条归档结果，无训练种子方差；最终集是同归档内的架构留出，不是独立基准。

## 8. 四个常见误解

- `s^4` 不是笔误（见 §2）。
- `psi_MP` 不是参数量，是容量；别和 `resources.json` 的 `total` 混。
- `Q_l` 不是激活方差（见 §7.1）。
- `beta` 只翻转方向，不换函数家族；旧版 `alpha = -beta`。
